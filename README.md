# HMD-Poser based Spine Posture Analysis

This project utilizes components and ideas from the [HMD-Poser](https://github.com/Pico-AI-Team/HMD-Poser) repository to perform real-time spine posture analysis using data from a Meta Quest HMD and an Android smartphone.

## Project Description

This project captures motion data in real-time, runs it through a pre-trained HMD-Poser model to estimate body pose, and calculates spine posture metrics (forward hunch and lateral deviation). The results are saved for later analysis.

## Dependencies

*   Python >= 3.9
*   PyTorch >= 2.0.1
*   Numpy >= 1.23.1
*   Scipy
*   The original `HMD-Poser` environment and its dependencies (`human_body_prior`, etc.).

## File Descriptions

*   `server.py`: The main script for real-time posture analysis. It starts UDP listeners, synchronizes data from the Quest and Android phone, builds the feature tensor, runs the HMD-Poser model inference, calculates spine angles, and saves the session data to a JSON file in the `RECORDS/` directory.

*   `udp_listener.py`: A utility module used by `server.py` to create simple, threaded UDP listeners for receiving sensor data.

*   `feature_builder.py`: A crucial module that takes raw sensor data (position and rotation from Quest; rotation and acceleration from Android) and constructs the precise input tensor required by the HMD-Poser model.

*   `spine_analyzer.py`: A module for post-analysis. It contains functions to calculate spine angles from SMPL joint data, which can be used in the notebook to re-process or analyze the output from the model.

*   `postura_tronco_hmd_poser.ipynb`: A Jupyter Notebook designed for offline analysis. Use it to load the JSON files generated by `server.py`, visualize the posture data over time, calculate statistics, and generate plots of the spine's pitch and roll.

## How to Run the Real-Time Analysis

1.  **Set up the Environment**: Ensure you have all the dependencies installed and that the HMD-Poser model files (`pretrained_model/`) and utility scripts (`utils/`) are in their correct locations as expected by the scripts.

2.  **Start the Server**: Run the main server script from your terminal. This will start listening for data from the Quest and the Android device.

    ```bash
    python server.py
    ```

3.  **Start Data Streaming**:
    *   On your Meta Quest, start the application that streams HMD and controller data to the IP address of your computer on port `5006`.
    *   On your Android phone, start the sensor streaming app that sends IMU data to your computer's IP on port `5005`.

4.  **Perform Calibration**: Once the server detects both devices, it will begin a calibration phase. Stand up straight for the first few seconds (`30 frames`) so the system can establish your neutral posture baseline.

5.  **Record a Session**: The server will record your posture for the duration of the session. You will see real-time feedback in the console, indicating your forward hunch (pitch) and lateral deviation (roll).

6.  **Stop the Session**: To end the recording, simply stop the data streaming from your Meta Quest. The server will automatically finalize the session, process the results, and save them into a new JSON file in the `RECORDS/` directory.

## How to Use the Jupyter Notebook

1.  **Launch Jupyter**: Start a Jupyter Notebook server in your project directory.

    ```bash
    jupyter notebook
    ```

2.  **Open the Notebook**: Open the `postura_tronco_hmd_poser.ipynb` file.

3.  **Analyze Data**: The notebook contains cells to:
    *   Load the `.json` session files from the `RECORDS/` directory.
    *   Process and plot the time-series data for spine pitch and roll.
    *   Calculate summary statistics for your posture during the session.
    *   Visualize the distribution of your posture angles.

    Follow the instructions and run the cells in order to analyze a recorded session.
